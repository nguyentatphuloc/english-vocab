# English Vocabulary Learning App (SRS)

Ứng dụng React học từ vựng tiếng Anh với Free Dictionary API, Web Speech API và Spaced Repetition.

## Tính năng

- Tìm kiếm từ vựng (IPA, loại từ, nghĩa, ví dụ)
- Phát âm từ/ví dụ bằng Web Speech API
- Lưu từ thành flashcard với metadata SRS
- Review mode (Easy / Good / Hard)
- Quiz mode 4 đáp án
- Dashboard thống kê + biểu đồ Recharts
- Words list (sắp xếp, xem lịch sử ôn tập, xóa từ)
- Lưu dữ liệu localStorage

## Công nghệ

- React (Create React App)
- Tailwind CSS
- Recharts
- React Router
- localStorage

## Cài đặt

```bash
npm install
npm start
```

Mở: `http://localhost:3000`
